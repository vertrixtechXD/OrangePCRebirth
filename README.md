# Orange PC Simulator (Rebirth)

Orange PC Simulator — фанатский мод на **PC Simulator** (Yiming), возродившийся на базе **1.8.3**.

Проект продолжен после ухода основателя: все изменения, внесённые в версии на базе 1.8.2, перенесены на свежую базу 1.8.3.

## Что в моде (по сравнению с оригиналом)

- 🟠 Брендинг Orange PC (главное меню, тег @orangePCsimu в About)
- 🖥 Меню «Пуск» + таскбар с часами и запущенными приложениями в ОС
- 📁 Поддержка папок в файловом менеджере (создание, двойной клик, системные папки)
- 📱 Мобильный хотбар / кастомизация управления (MobileCustomizeManager)
- ⌨️ Управление с клавиатуры/мыши (PC keybinds: PcKeyBinds, WASD)
- 🎯 FOV-слайдер в меню паузы
- 🖼 Кастомные обои (внутриигровые файлы + из галереи устройства)
- 🖨 Улучшенный принтер (Apson A3, разрешение печати, скорость)
- 💣 Система горения и взрывов комплектующих (Supply: burn/explode)
- ☎️ Телефон (Office Phone), кальян/вейп, торговая точка с газетой
- 🛒 Расширенный магазин: RTX 4080 / 4080 Ti, GTX 1060, проектор, TV, Crate, WallMount и др.
- 🔍 «Ogle» — браузер с домашней страницей и поиском по сайтам
- 🎁 Промо-коды (Giveaway)
- 📄 Сохранения в формате `.opc`
- 🇷🇺 Русские тексты в интерфейсе магазина, доработки UI

## Версия

База: **PC Simulator 1.8.3** (Unity 2022.3.62f3)
Мод: **1.8.30**
